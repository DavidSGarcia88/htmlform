# Registration Form

This is a simple, styled registration form built using HTML and CSS. It collects essential user information such as first name, last name, email, and password. Additionally, users can choose their account type, upload a profile picture, input their age, and select how they heard about the service.

## Features

- **Basic Information**: Collects user's first name, last name, email, and password.
- **Account Type Selection**: Users can choose between "Personal" and "Business" account types.
- **File Upload**: Option to upload a profile picture.
- **Age Validation**: Ensures the user is between 13 and 120 years old.
- **Referrer Selection**: Allows the user to choose how they heard about the service.
- **Bio**: Text area for users to provide a short bio.
- **Terms & Conditions**: Users must agree to the terms before submitting the form.

## Technologies Used

- HTML
- CSS

## Styling Overview

The form is styled to create a modern and clean look with the following details:

- **Background**: A dark background (`#1b1b32`) with light text color (`#f5f6f7`).
- **Form Layout**: The form is centered on the page with a flexible width, making it responsive.
- **Text and Fields**: Inputs and text areas have a dark background with light text, and borders match the dark theme.
- **Submit Button**: Styled with a distinctive background color (`#3b3b4f`) to match the form's theme, with white text.
- **Typography**: The form uses the Tahoma font with a base font size of 16px.
  
## How to Use

1. Clone the repository or download the files.
2. Open the `index.html` file in your browser to see the form.
3. The form will send the data to the demo URL when submitted (as specified in the `action` attribute).

## Instructions

1. **Fill in the fields**: Complete all required fields marked with an asterisk (*).
2. **Submit**: After filling out the form, click the "Submit" button to send the data.
3. **Customization**: Modify the form's `action` attribute to integrate with your backend or service.
